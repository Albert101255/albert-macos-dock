Albert macOS Dock

GNOME Shell Extension
→ GitHub Repository

Interactive Magnification Simulator

Hover your cursor across the dock at the bottom of your screen to experience smooth cosine-interpolated magnification and dynamic neighbor displacement ported directly from the extension's dash.js mathematics.

Max Magnification Scale 1.8x
Influence Radius Factor 3.5×
Base Icon Size 52px

• Cosine Bell Curve Interpolation

Uses Math.cos(offset / radius * Math.PI / 2) within the influence boundary to eliminate jerky step transitions and produce an authentic macOS magnification curve.

• Neighbor Displacement Math

Dynamically computes expansion offsets so neighbor icons smoothly glide outward along the baseline without overlapping or distorting layout alignment.

• GSettings Customization

Fully configurable via GNOME Extension Preferences: adjustable size limits, animation damping, auto-hide triggers, and multi-monitor placement.
